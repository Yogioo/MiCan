# 拆存档：逻辑、布局、运行产物、正文各归各处

Status: accepted

[ai-evolution.md](../ai-evolution.md) 第二节。现在 `mican.json` 一份装了四样性质不同的东西：
图的逻辑、坐标和视图、每跑一次就变的 `results`、文本节点正文的一份副本。pi 改一根边要先在坐标和运行噪声里找节点；
`results` 让每次进化的 commit 夹着运行结果，回滚也把它卷回去；正文打开时不从 md 读回，pi 改 md 只能靠进化里的兜底（ADR-0022）。

决定：

- **`mican.json` 只留逻辑**（`FORMAT_VERSION` 升到 7）：`settings`、`board`、`nodes`、`edges`。
  节点只有 `id` / `name` / `kind`，以及各自的 `command` / `cwd` / `extension` / `consts` / `pick` / `slot` / `schedule` / `file`。
- **布局进工作文件夹顶层的 `mican.layout.json`**：`view`，和按 id 记的节点 `x` / `y` / `w` / `h`。
  逻辑为准：逻辑里有、布局里没有的节点，打开时摆在它第一个上游的右边（没有上游就摆在视图中间）；布局里多出来的条目忽略。
- **进化的快照、回滚、commit 把布局文件也圈进去**（三层之外多这一份），pi 仍然只改三层，提示词里不让碰布局。
  这样进化前用户摆的位置进了快照，回滚、撤销时位置跟着节点一起回来；进化后前端重开给新节点摆的位置，下一次快照带上。
- **`results` 进 `.mican/results.json`**，只由后端写：运行器跑完补一格、调度器记一笔触发。前端不再整包带着它落盘。
- **文本正文只在 `docs/` 的 md**：打开时后端按每个文本节点的 `file` 读 md 给前端；md 不在就是空文本，下次落盘写出来。
  前端落盘照旧送 `docs`，存档里不再有 `text`。
- **节点加 `name`**：画布内唯一的可读名，新建时生成（文本节点取文件名、扩展节点取扩展目录名、命令节点取命令第一个词、其余取种类），
  撞名就加 `-2`、`-3`。边仍然写 id：缓存文件、`.log`、运行历史都按 id 关联，改 id 历史就断。
- **旧存档打开时就地拆**：后端打开 6 版及以前的存档，先拆成上面三份写回盘，再往下走。拆法放在 `src/core/serialize.mjs`，前后端共用。
  之后后端的读者（运行器、调度器、进化的校验）只认 7 版。
- 进化跟着收：`syncTexts` 删掉；提示词里「别动 view 和 results」「x / y / w / h 摆在上游旁边」删掉，换成「节点靠 `name` 找，新节点给 `name`」。
  ITERATE.md 的「画布」层改成只说 `mican.json` 的逻辑字段。

## Considered Options

- **布局放 `.mican/`**：进化只 commit 三层，放顶层会一直是脏的。但 `.mican/` 是缓存目录，布局是用户摆出来的，不是运行产物。
  改成调整进化的 commit 范围。
- **另造一门图语言**（一行一根边，render 出来改完再合回去）：多一层解析和合并，出错面更大。留作以后给人看的视图。
- **id 改成可读名**：历史和缓存文件都断，还得做一次重命名迁移。只加 `name`。
- **正文两边都存，以新的为准**：要比时间戳，两边都能被外部改。只留 md 一份。

## Consequences

1. 撤销快照本来只取 `nodes` / `edges`，现在还要带上布局那一部分（前端内存里照旧是一张图，拆只发生在落盘和打开）。
2. 画布上拖一下节点只改布局文件，git 里看得出是「只挪了位置」还是「改了逻辑」。
3. 运行器和调度器不再现读现改 `mican.json`，前端整包落盘和后端补写结果不会再互相盖。
4. 回滚和进化的 commit 不再夹运行结果；进化改完前端重开时，布局和结果原样还在。
5. `name` 眼下只给 AI 用：画布上显不显示、能不能改，另议。
