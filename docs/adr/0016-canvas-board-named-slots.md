# 面板：画布上的名字→字符串表

Status: accepted · 已实现

链身份一类的值（如工单网址）原先只能靠数据边到处广播，或写进每个节点的常量。节点已有常量和扩展默认值，缺的是**跟这份画布走的一张共用表**，`{{名字}}` / `[[名字]]` 在没边、没常量时能读到。

决定：加 **面板** —— 存档顶层一个 `board` 对象（名字→单行字符串）。不是新节点，没有 get/set，也不在边上流动。文本节点仍是 markdown。空表不写进存档。旧存档没有这个键，读进来就是空表。`FORMAT_VERSION` 仍为 6：加载器不必用版本号区分。

```
框里填了常量      → 用它
有数据入边        → 用边上的值（连了却没跑过照旧报错，不从面板补）
都没填            → 用面板上同名那一格（非空）
面板也没有        → 用清单的 defaults（ADR-0015）
```

`{{名字}}` 拿正文，`[[名字]]` 把同一串当路径，跟常量一样。设置窗口「跟这份画布走」里改行；重名以后面那一行为准。改面板跟改存档配置一样：落盘、不进撤销栈。

## Considered Options

- **塞进 `settings` / `CANVAS_FIELDS`**：那张表只收标量，还得过 coerce。独立 `board` 少动那条路。
- **get/set 节点或黑板上流动**：多一种节点、多一种边，问题只是「这份画布几个共用名字」。
- **FORMAT_VERSION 7**：没有这个键就是空表，不必涨版本。

## Consequences

1. 后端 `loadGraph` 把 `board` 交给 `collectVars`，定时器进的链也走同一份存档。
2. 输入框在没边、没常量、面板有值时显示「面板 …」；连了边仍写「由连线提供」。
3. 撤销只快照节点与边，面板与存档配置同命运。
