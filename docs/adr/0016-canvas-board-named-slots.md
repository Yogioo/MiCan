# 面板：画布上的属性表

Status: accepted · 已实现

链身份一类的值（如工单网址）原先只能靠数据边到处广播，或写进每个节点的常量。节点已有常量和扩展默认值，缺的是**跟这份画布走的一张共用表**。

决定：**面板** —— 左侧窗口列出属性（名字 + 默认值）。存档顶层 `board` 只记声明（名字→单行默认值）。真正的值落在 `.mican/board/<名字>.md`，跟节点缓存一样跟着工作文件夹走，不靠内存。空表不写进存档。旧存档没有这个键，读进来就是空表。`FORMAT_VERSION` 仍为 6。

窗口里的属性可以拖到画布：默认落下获取节点，边上「写」落下写入节点（ADR-0019）。

```
框里填了常量      → 用它
有数据入边        → 用边上的值（连了却没跑过照旧报错，不从面板补）
都没填            → 读盘上那份 md（没有就用声明的默认值）
面板也没有        → 用清单的 defaults（ADR-0015）
```

`{{名字}}` 拿正文，`[[名字]]` 指那份 md 的本机路径。改面板跟改存档配置一样：落盘、不进撤销栈。设置窗口不再改这一张表。

## Considered Options

- **只放设置窗口**：看不见、拖不出去，链上还是要拉线。
- **值只进存档 / 只进内存**：换地方或刷新就对不上；跟「缓存文件是值」也不一致。
- **FORMAT_VERSION 7**：没有这个键就是空表，不必涨版本。

## Consequences

1. 后端跑链时按盘上的 md 叠到声明表上，再交给 `collectVars`。
2. 输入框在没边、没常量、面板有默认值时显示「面板 …」。
3. 撤销只快照节点与边，面板与存档配置同命运。
