# 扩展的默认值是留空时的回退，不是拖出来时的初值

Status: accepted · 已实现

[ADR-0013](./0013-extension-declaration-is-a-static-manifest.md) 的 `defaults` 一开始是**初值**：
拖出来的节点上先把那些常量写进 `consts`。用起来才发现，那等于把「扩展这份清单」抄一份进每个节点：

- 拖出来的 pi 节点上，模型/工具/技能/MCP/系统提示词/其它六个框里全是一句保留词（当时是 `不加`，
  后来改成了 `空`）。
  那是**扩展的保留词**，用户既没填过也不太看得懂，纯粹是噪声。
- 改一次清单，抄出去的旧值一个都不动 —— 用户以为「这六个开关跟着扩展走」，其实不跟。

决定：**`defaults` 只在留空时兜底。** 节点上那个框空着、又没有数据入边，才拿清单里的默认值顶上；
拖出来的节点不写任何 `consts`（框里只留一句灰色的「默认 空」）。

```
框里填了常量      → 用它
有数据入边        → 用边上的值（边优先，照旧）
都没填            → 用清单的 defaults
清单也没有默认值  → 报「既没有入边也没有填值」（照旧）
```

于是「一个开关什么都不加」这件事有了正经表达：**留空**。那句保留词退回成脚本自己的约定
（pi 那份 `run.mjs` 认 `空`），不再需要用户去填 —— 清单里那句 `模型: 空` 只是让留空有值可兜。

## Considered Options

- **维持初值，只在清单里不写 `defaults`**：拖动干净了，但每个开关都会变成必填 —— 漏一个就停在
  「没有入边也没有填值」上，等于把噪声换成报错。
- **前端认那句保留词，不填它**：前端就得知道某个脚本认哪个词。`空` 是 pi 那份脚本
  跟它自己的约定，画布不该有一份副本。
- **空值就地删掉整个 token**：改动在通用的变量替换里，会连手写命令节点一起改 —— 那些地方
  「空」确实是个错，不该静默消失。默认值这条路只影响扩展节点。

## Consequences

1. 节点存档里不再出现「没人改过的常量」，拖出来的节点是干净的。
2. 改 `EXTENSION.md` 的 `defaults`，**所有**引用它的节点立刻跟着变；想钉死一个值就填进节点那个框里。
3. 默认值在**运行时**由后端补（`runner` 现读清单，交给 `collectVars` 兜底），存盘里没有它 ——
   跟 ADR-0014「节点只是引用」同一条路。
4. 旧画布照常跑：那些节点上填着的常量照旧原样转发。只有保留词换过名字这件事要用户动一下手 ——
   老节点上若还留着旧词（`不加`），把它清空就是「用默认值」，不清掉它会被当成参数送给脚本。
