# 注释写在触发节点上

Status: accepted · 已实现

一份画布上多枚入口、多枚定时器时，人想对 AI 说「改哪条链」没有可指代的名字。图上那几枚入口长得一模一样（标题只有两个字「入口」），
定时器也只在顶上说「每 30 分钟」。节点上现有的 `name` 帮不上：新建时生成（触发节点就是 `entry` / `entry-2` / `timer`），
画布上不显示也不能改，[ADR-0023](./0023-split-archive.md) 第 5 条把它留作另议。

这一单把那个「另议」结掉。

## 决定

- **注释挂在触发节点上，不是链上。** 链的身份照旧看链身从哪个会跑的节点起步（[ADR-0027](./0027-busy-chain-blocks-a-trigger.md)），这条不动；
  注释的语义是「**从这枚触发起步**的那条链叫什么」。两枚触发指同一个链身时各有一句，不判重、不提示。
- **新加一个字段 `comment`，`name` 一个字都不动。** 两者分工：`name` 是 AI 找节点的索引键 —— 程序生成、画布内唯一、稳定；
  `comment` 是人写的白话 —— 不唯一（两枚入口都想写「抓漏洞」不该报错）、指代用、随时可改。
- **只长在 `entry` / `timer` 上**，空着不写进存档，格式版本不升（跟 ADR-0027 的 `onBusy` 同一种做法）。
- **单行，长在节点上，双击就地编辑**：入口节点上顶掉原来那句灰字「链从这里开始」（空着时它当占位提示），定时器上放正文区第一行。
  超出截断、悬停看全 —— 跟命令节点标题那套一样。
- **「被占」的提示改用点火那一枚的注释**：后端的 `chainName`、前端脚上那句「让路 · … 在跑」，从此说人话而不是「从「plan」起步的链还在跑」。
  运行时本来就没有歧义：`run.nodeId` 就是点火的那一枚。
- **复制不带。** `duplicate.mjs` 按 kind 挑字段，`entry` / `timer` 那两项**不加** `comment`。注释回答的是「这条链叫什么」，
  而复制出来的那枚指的另一条链 —— 抄过来正好撞在这次要解决的痛点上：图上多出一句指错人的中文，人和 AI 都被它带偏。
  `onBusy` / `schedule` 不一样，那两项是这枚节点自己的行为配置，注释是指代。
- **谁都能改，AI 也能改，不给它上锁。** 注释是普通字段：AI 改了链顺手把它改对，改动进进化的 diff 和 commit，撤销与回滚带着它一起退
  （前端撤销快照取的是整份节点，进化的快照圈的是 `mican.json`）。代价认下来：没有「人写的这句不许动」这回事。

## Considered Options

- **把 `name` 做成可改可显示**（ADR-0023 留的那条路）：本来能一举两得 —— AI 已经靠 `name` 找节点，改了它对话两边同时受益。但 `name` 是唯一索引键，
  人写白话必然撞名，撞名要报错就烦；而注释撞名不该报错。分成两个字段。
- **注释挂在链身起步的那个会跑的节点上**：那才是真正的「链名」。但用户指不到 —— 得先在图上自己找出「第一个会跑的节点是谁」，
  而用户手上现成的锚点是那枚入口/定时器。
- **AI 只在注释空着时补写**：跟「AI 也能改」冲突。用户拿这句当指代锚点，AI 改了链却留着旧注释，那句中文就变成假的。
- **画布上提示「这两枚触发指同一条链，注释不一致」**：为一个还没出现过的场景加机制。
- **代码兜「入口节点被重建时把注释搬过去」**：机器判不了旧的那枚和新的是不是同一个 —— 注释是人写的白话，没有可比对的键。
- **写进文本节点或边上**：文本节点指得到，但得在图上额外连一根线才有关系；边没有「链」这个身份，挂不上去。
- **所有节点都长这个字段**：节点标题栏要为它全改一遍，而这次要的只是「链叫什么」。真需要长文本的用户手上已经有文本节点。

## Consequences

1. `src/core/serialize.mjs`：`logicOf` 的 `entry` / `timer` 各多一个 `commentPatch`；`deserialize` 读回来，缺就是空串。格式版本仍是 7。
2. `src/core/graph.mjs` 多一个 `setNodeComment`（跟 `setNodeBusy` 同一段）；`src/ui/nodes.mjs` 的触发节点 body 多一行 `.node-comment`
   （`.node-hint` 退休），双击改走一个新的 `beginCommentEdit`（对着 `beginFileEdit` 写）。
3. `server/runner.mjs` 的 `headName` 更名为 `chainName`，与 `src/ui/nodes.mjs` 的 `nameOf` 一起改成「点火那一枚的注释优先，没有才回落到链身起步节点的 `name`」。
4. `src/core/duplicate.mjs` 不动 —— 白名单本来就不带它，这就是要的那一头。
5. `CONTEXT.md` 新词「注释」，并写明复制不带它；`ITERATE.md` 不动 —— 注释是普通字段，AI 想改就改，不用额外规矩。
6. 诊断（`extensions/diagnose`）与运行历史暂时不带注释：那边按节点 id 列，链的名字要到 P1 的「事件日志」那一单才有席位。
