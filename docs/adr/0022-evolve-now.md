# 立即进化：固定顺序，进化期间只读

Status: accepted · 已实现

[ai-evolution.md](../ai-evolution.md) 的「最小闭环」先落一个按钮：工具条上的「立即进化」，可附一段进化提示词。
开关、触发条件、进化记录、撤销还没做。

决定：

- 步骤固定在 `server/evolve.mjs`：停下在跑的链 → 诊断 → 快照 → pi 改工作文件夹 → 校验 → commit（有上游就 push）。
  校验不过就回滚到快照，把原因交回 pi 重改，总共最多 3 次。诊断和 pi 用内置库里那两份，工作文件夹不用拷。
- **进化期间只读**：运行器不起新运行，定时器到点跳过且不写回存档，后端拒收前端的落盘，画布和面板点不动。
  做完前端从盘上重开，撤销栈清空。
- **只圈三层**：快照、回滚、commit 都只动 `mican.json`、`docs/`、`extensions/`，`.mican/` 里的运行产物不跟着卷。
- **正文以 md 为准（只在进化里）**：pi 改完后，文本节点的 `text` 按 `docs/` 里那份 md 覆盖。存档格式没动。
- 不是 git 仓库就不让进化。提供商和模型是全局配置（`evolveProvider` / `evolveModel`），空着让 pi 自己选。
- 每次的提示词和过程记在 `.mican/evolve/<时间>-prompt.md` 和 `<时间>.log`。
- **进化窗口**：进化一开始右边弹出一个窗口，每秒拉一次 `/api/evolve/watch`，滚动显示过程（动作行藏掉）。
  同一个接口带回盘上此刻的画布（文本节点正文按 md 给），画布原地换上，跟进化前不一样的节点描一圈紫边；
  画布还能平移缩放，只是点不动。关掉窗口才收掉紫边。

## Considered Options

- **进化期间照常编辑，做完合并**：pi 和前端都改 `mican.json`，要么互相盖，要么得做三方合并。否掉。
- **先拆存档（ai-evolution.md 第二节）再做按钮**：更干净，但要升格式版本；先用「只读 + 重开 + md 回写」跑通闭环。
- **不是 git 仓库就自动 `git init`**：会在用户不知情时建仓库。改成拒绝并提示。

## Consequences

1. 进化期间在画布上的改动留不下来（本来也点不动）。
2. 新扩展的试跑只给清单里的默认值，缺的输入原样留着 token；脚本照契约该吐一份失败 JSON，吐了就算过。
3. 「是不是这次改动之后才开始的」还没做，诊断看不出某次进化有没有把链改坏。
