# 选中可以复制

Status: accepted · 已实现

框选之后只能删、拖，再要同样的一批节点得从零建。需要的是把当前选中做成一份新的。

决定：`Ctrl/Cmd+C` 抄进内存，`Ctrl/Cmd+V` 贴出来，`Ctrl/Cmd+D` 一步抄贴（一次撤销）。只抄选中的节点，和两端都在这批节点里的边；只选了边不算。新 id，位置错开 `gridStep`。反复粘贴从抄下时的原点再错一格。贴完选中新节点。文本节点另写 `docs/<新id>.md`。命令节点抄命令、扩展、运行目录、常量，不抄结果。数据边带着 `fromPort`（若有）。面板不抄。剪贴板只在内存里；正文里选着字时不抢 `Ctrl+C`。

## Considered Options

- **和系统剪贴板抢**：正文里划字复制还要用系统的；节点这一份不进盘、不进系统剪贴板，除非系统那份本来就是空的。
- **悬空边也抄**：去处在选中外面，贴出来会变成断边。不要。
- **结果一起抄**：克隆是没跑过的，缓存文件跟节点 id 走，抄过去也对不上。

## Consequences

1. 两个入口挂在同一条链上是用户自己的事，复制不管。
2. 撤销还原图结构；已经写下的那份新 md 不会跟着删。
3. 刷新页面剪贴板没了。
