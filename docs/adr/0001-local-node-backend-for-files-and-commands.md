# 引入本地 Node 后端承载文件读写与命令执行

MiCan 原本是纯前端应用，数据只活在 `localStorage` 和手动下载的 `.json` 里。后来要求「节点对应磁盘上的 md 文件」和「节点里配的命令能真的跑起来」。浏览器的 `File System Access API` 能读写用户选的文件夹，但不暴露绝对路径，后端 shell 拿不到 `cwd`，所以这两件事在纯浏览器里凑不到一起。

决定：在 Vite 上挂一个本地 Node 中间件，由它持有工作文件夹并暴露文件读写与命令执行接口，前端只发相对路径。

被否掉的两条路：命令节点只做「复制命令」不真跑（需求要跑）；换 Electron/Tauri 桌面壳（能力最全但整个项目形态变了，过重）。

代价：只在 `npm run dev` / `preview` 下可用，不能静态部署 —— 对一个本机自用工具可接受。
