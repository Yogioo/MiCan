# 获取节点与写入节点

Status: accepted · 已实现

面板上的属性要能当节点用：拖到画布上读，链上也能写回去。值不能只活在内存里。

决定：两种会跑的节点，都只记一个属性名（`slot`）。

- **获取**：读 `.mican/board/<名字>.md`；没有这份文件就用声明的默认值，并当场写下。读到的正文就是它的值，也写进它自己那份节点缓存。
- **写入**：来路跟提取节点一样（数据入边，没有就用执行来路），写进那份 md。写进去的就是它的值。

从左侧面板拖一行到画布是获取；拖边上的「写」是写入。节点上不改属性名，改名在面板里，画布上绑着旧名的节点跟着改。缺字段跟提取节点一样：不 spawn，`resultMeta` 只记时间。

## Considered Options

- **只靠 `collectVars` 回退、不建节点**：省一种 kind，但链上看不见「这里读/写了哪个名字」，也没法把属性当数据边的来路。
- **值写进节点自己的 `.out` 当共用**：多个获取节点各写各的，对不上「这一份属性」。
- **新边族**：为属性再加一种边，比多两个会跑的节点重。

## Consequences

1. `runnable` 含获取 / 写入，执行边、复制、存档元信息都走这条。
2. 写入跑完，下一次获取和 `{{名字}}` 都读到新 md。
3. 属性从面板删掉，节点还在，标红；那份 md 一起删。
