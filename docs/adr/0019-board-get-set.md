# 获取节点与写入节点

Status: accepted · 已实现

面板上的属性要能当节点用：拖到画布上当变量读，链上也能写回去。值落在 `.mican/board/<名字>.md`。

决定：两种节点，都只记一个属性名（`slot`）。

- **获取**：像文本节点。值就是那份 md，只有数据端口，不进执行链、不用跑。拉到命令节点上，跟拉一份文档一样。
- **写入**：会跑的节点，执行两端都在。来路跟提取节点一样（数据入边，没有就用执行来路），写进那份 md。写进去的就是它的值。

从左侧面板拖一行到画布是获取；拖边上的「写」是写入。节点上不改属性名，改名在面板里，画布上绑着旧名的节点跟着改。

## Considered Options

- **获取也当会跑的节点**：先跑再取值，链上多一截，用起来不像变量。
- **只靠 `collectVars` 回退、不建节点**：省一种 kind，但看不见「这里读了哪个名字」，也没法把属性当数据边的来路。
- **值写进节点自己的 `.out` 当共用**：多个获取节点各写各的，对不上「这一份属性」。

## Consequences

1. `runnable` 只含写入，不含获取。载入时挂在获取上的执行边丢掉。
2. 写入跑完，获取节点上看到的正文和 `{{名字}}` 都读到新 md。
3. 属性从面板删掉，节点还在，标红；那份 md 一起删。
