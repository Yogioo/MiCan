# 内存是唯一真相源，只有「保存」写磁盘

Status: superseded by [ADR-0003](./0003-changes-are-mirrored-to-disk-immediately.md)

引入工作文件夹后，磁盘上的 md 文件与内存里的节点文本随时可能不一致。有两种办法：编辑时实时同步到磁盘（文件即真相源），或者内存持有状态、由用户显式保存。

决定：内存是唯一真相源，磁盘永远是「上次保存」的快照。新建节点、改名、删节点、运行命令都只是内存里的改动，点「保存」时一次性落盘（先处理全部 md，最后写画布存档）。因此也不保留任何自动落盘兜底，包括原本的 `localStorage` 自动保存。

理由：两个真相源必然打架，而「文件被悄悄改掉」比「忘记保存」更难察觉、更难挽回。代价是刷新页面会丢掉未保存的改动 —— 用 `beforeunload` 警告兜住。

命令节点没有例外：运行命令只把输出写进下游节点的内存文本，仍然要等保存才落到它们的 md 文件。
