# 改动即镜像落盘，取消显式保存

ADR-0002 把两件事捆在一起：内存是唯一真相源、只有「保存」写磁盘。后者带来两个后果：断电丢掉全部未保存改动；以及磁盘上的 md 随时落后于内存，「把上游输出写进文本节点、再让下游命令去读那个文件」这条路在链里是断的（下游读到的是上次保存的旧内容）。

决定：保留「内存优先」（冲突时内存赢），废掉「只有保存写磁盘」。一个改动单元结束（停止编辑、停止拖拽、增删边与节点）就防抖落盘，跑任何命令之前先强制落盘。没有「保存」这个动作，也没有「未保存改动」这个状态，只留「另存为」用来换工作文件夹。

## Considered Options

- **追加日志 + 断电回放**：内存仍是唯一真相源，改动追加进日志，重开时回放。能保住 ADR-0002 一字不动，但治不了 md 过期，还多一套日志与回放机制。
- **只让文本节点即时落盘**：画布结构仍靠显式保存，断电后节点位置与边全丢。
- **localStorage / IndexedDB 兜底**：ADR-0002 已否掉，且又造出第二个真相源，清缓存即丢。

## Consequences

工作文件夹从此归 MiCan 管：同一份 md 在别处被改过时，内存会覆盖它。落盘前比对该文件与自己上次写进去的内容，不一致就**跳过那个文件**并在节点上提示，给「覆盖 / 以文件为准」两个动作，不弹窗打断。画布存档 `mican.json` 只有 MiCan 写，不做这项检查。

未打开工作文件夹时没有落盘目标，自动落盘不生效 —— 所以「打开工作文件夹」仍是断电可续的开关。
