---
name: pi
description: 在运行目录里让 pi 干一件事，把它的回话包成一段 JSON
entry: run.mjs
args: --prompt [[提示词]] --留会话 {{留会话}} --provider {{提供商}} --model {{模型}} {{工具}} --append-system-prompt [[添加系统提示词]]
defaults:
  留会话: false
  提供商: 空
  模型: 空
  工具: 空
  添加系统提示词: 空
outputs:
  ok: json:ok
  text: json:text
  reason: json:reason
route: ok
---

一份现成的 pi 封装。这是**一遍拷贝**，不是引用：把 `pi/` 整个目录拷进工作文件夹的
`extensions/` 底下，菜单里就多出「pi」这一项，拖出来即可用。

## 怎么接

`[[提示词]]` 优先当**路径**看：接一个文本节点上去，收到的是它那份 md 的绝对路径，`run.mjs`
读出正文从 stdin 递给 pi —— 顺便，提示词就成了画布上一个能看能改的方框。**路径读不到就当正文本身**：
一句短提示词直接在端口旁边的框里写（`hi`、`跑一下测试`）也能跑。
看着像路径却读不到，那是真错，会停在「提示词读不到」—— 但「像路径」的判据很窄：
**整串没有空格、也不是网址**，才按路径看。所以含反斜杠或斜杠的提示词（`printf 'a\r\n'`、
`改掉 C:\projects\x`）不会被误判。

    文本节点（提示词）--[[提示词]]--> pi 节点 --> 文本节点（回话）

pi 在**节点的运行目录**里跑（节点自己设的 > 画布的运行目录 > 工作文件夹），
所以「看看这个仓库的 git 状态」「按这份提示词改代码」这类事，直接以那个目录为家。

## 留会话：`true` / `false`

六个输入里只有它不是一个「参数串」，它只认 `true` / `false`（拖出来是 `false`）：

- **`false`（默认）**：这次会话不落盘。链会重跑，定时器更是每 30 秒一趟 —— 留就是一路涨。
- **`true`**：这次会话落进 pi 自己的会话目录，过后能 `pi -r` 翻回来看它到底想了什么、调了哪个工具。
  要复盘的时候才打开它。

填了别的会停在这一步报错（`留会话 只认 true / false`）。

## 跑起来看得见（不是黑盒）

`run.mjs` 用的是 `pi --mode json`，不是 `-p`：`-p` 只吐回话，它在干什么一概看不见。
事件流被翻成人话写到 **stderr**，而 MiCan 把 stderr 当**诊断** —— 带着淡色铺在节点正文上，
跑完存成缓存文件旁边的 `.log`，刷新页面也还在。

```
   0.0s · 起于 D:\work\repo
   1.8s ─ 第 1 轮
   3.2s → read src/app.mjs
   3.4s ← read export function main()…（共 42 行）· 0.2s
   7.1s ─ 第 2 轮
   9.0s → bash node --test
  16.3s ← bash 12 个用例全过（共 14 行）· 7.3s
  18.9s 它把 `main` 里的连接超时改成了 5 秒，测试全过。
  19.1s · pi 退出码 0 · 2 轮 · 2 个工具 · 19.1s（工具 7.5s / 模型 11.6s）
```

几条要紧的：

- **行首那根时间栏**是「从起跑算到第几秒」。它让「八步跑了十秒」和「一步卡了三分钟」分得开 ——
  上一行和下一行的秒数差多少，中间就真空了多久。
- **动作行尾的秒数**是「这一下花了多久」；最后一行把总时长拆成**工具在跑的**和**模型在想在写的**两半。
- **思考不铺出来**，只报「想了想（N 字）」：那是模型的草稿纸，铺满节点正文反而把动作挤没了。
  要复盘它到底想了什么，把「留会话」打开（见上一条）。
- **卡住和正在想长得一样**，所以静下来超过 20 秒会写一行 `… 已经 40s 没有新动静`。
- **漏出来的裸词会被当场拦下**：命令行上只要有一个词不在开关后面，pi 就会把它当成**提示词** ——
  它不报错，只是让 agent 多收到一条独立的消息（于是它转头去办了另一件事）。这不是「跑得不对」而是
  「跑的是另一件事」，所以会**停在起跑线上**（一个进程都没起），而不是跑完两轮才让人起疑：
  `✗ 「sub2api」不是开关，会被 pi 当成提示词（一条独立的消息）`。
- **值一点没变**：stdout 还是那一段 JSON。诊断走另一条路（stderr），不混进值、不进缓存文件，
  下游的提取节点和 `[[结果]]` 都不受影响。

## 四个开关

开关框有两种写法，看 `args` 那行里**有没有带前缀**：

| 端口 | `args` 里长什么样 | 框里写什么 | 写 `空` 的意思 |
| --- | --- | --- | --- |
| 提供商 | `--provider {{提供商}}` | **只填值**：`openai`、`anthropic` | pi 自己选的提供商 |
| 模型 | `--model {{模型}}` | **只填值**：`sonnet`、`openai/gpt-4o` | pi 自己选的模型 |
| 工具 | `{{工具}}` | **整串开关**：`--tools read,bash`、`--no-tools`、`--exclude-tools ask_question` | pi 的默认（全开） |
| 添加系统提示词 | `--append-system-prompt [[添加系统提示词]]` | 整段提示词从**文本节点**连过来（拿到的是那份 md 的绝对路径）| 不追加 |

前两个的前缀写在清单里（`--provider {{提供商}}`），框里只填值 —— 前缀写一次，所有引用它的节点都受益，
也免得谁漏写那个 `--`。后两个没法这么干：工具那一栏要能表达 `--no-tools`、`--exclude-tools ask_question`
这种**换一个开关**的写法，所以框里给的是整串。**填错了会当场停下**，不会跑歪（见「跑起来看得见」最后一条）。

`空` 是唯一的保留词，意思是「这条开关不要」。**框留空就是它** —— 节点跑起来会拿 `defaults` 里的 `空`
顶上，框里那句灰色的「默认 空」说的就是这事。它有两种落地方式，`run.mjs` 都认：

- 清单里带了前缀（`--provider {{提供商}}`）：`空` 连**前面那个开关一起抹掉**，等于这个开关没写。
- 清单里是整串（`{{工具}}`）：`空` 自己就是那整串，抹掉它等于没这个开关。

几条要紧的：

- **提供商和模型常常要一起填**：光填模型，pi 得自己在你的模型表里认它，同名的模型分属两家就可能
  挑错。报「找不到模型」时，先把提供商补上。模型也收 `provider/id` 这种写法，一条就够。
- **值里带空格就在框里自己加引号**（`--append-system-prompt "C:\我的 提示词.md"`）。框里的话是先
  交给命令行再传给 pi 的，引号该加还是得加。
- **多行的东西不能走 `{{ }}`**：`{{ }}` 取的是**正文**，而正文里只要有一个换行就写不进命令行
  （画布会停在「的值有换行，放不进命令行」）。多行的值要么摆一个**文本节点**、用 `[[ ]]` 把那份 md 的
  路径传过去，要么填进扩展自己的脚本里让它去读。
- 添加系统提示词那一栏就是给这个用的：`[[添加系统提示词]]` → pi 收到一份 md 的绝对路径，
  而 `--append-system-prompt` **收文本也收文件内容**（pi 自己的帮助里写着 “Append text or file contents”），
  它会去读那份文件。好事成双：那份提示词就成了画布上一个能看能改的方框。
  短到一行以内的也可以直接写在框里（那时它就是文本本身）。
- 技能和 MCP **没有框，因为不用填**：pi 自己会扫技能目录、自己会读 MCP 配置。要指定才补开关 —— 见下一条。
- 多一个开关也不改代码：想再加一个（`--thinking high`、`--skill <目录>`、`-a`……），往 `args` 那行补一个
  `{{名字}}`，在 `defaults` 里给它写 `空` 就行。想让「框里只填值」，就把前缀自己写进 `args`（`--skill {{技能}}`），
  `空` 会自动连它一起抹掉。`run.mjs` 只认 `--prompt`、`--留会话` 和 `空`，别的一律转手。

## 拿到什么

stdout 永远是**一段合法 JSON**：

    {"ok":true,"text":"pi 的回话"}
    {"ok":false,"reason":"一句话说明哪里不对"}

清单声明了三个出口：`ok`、`text`、`reason`，选路看 `ok`。执行边上写 `true` / `false` 即可，不必再接提取节点。
`text` 里可以有换行；从 `text` 那个出口拉到下游文本节点，或用 `[[ ]]` 拿边车路径。
没写出口名的数据边仍送整份 JSON。

若回话本身是一段 JSON **对象**，脚本会把对象里自己的原始值（字符串 / 数字 / 布尔）抄到顶层，不覆盖 `ok`。
于是工作文件夹里这份扩展可以再声明 `IsEnough`、`msg` 这类出口 —— **多出来的键只在回话本身是 JSON 时才有**。对象和数组不会被抄上去。

**退出码跟着 pi 走：**

- pi 非 0（认证没了、超时、崩了）→ 节点标红、链停在这儿。那是**环境失败**，脚本不去粉饰它。
- pi 正常退出，但一个字没回 → 吐 `{"ok":false}` 且退出码 0。这是**业务空转**，交给链自己
  决定「重试 / 退给人」。

## 留会话那一处没有写在 args 里

`--no-session` 不在 `args` 那行 —— 改由 `留会话` 这个输入决定，`run.mjs` 里换。

- 想加 `-a`：`--mode json` 和 `-p` 一样是**非交互**的，**不弹**信任提示。没有存过信任决定时，
  pi 会**静默忽略**运行目录里的项目配置（AGENTS.md、`.pi/settings.json`、技能）—— 同一份提示词，
  在终端里手敲和在这儿跑，行为可能不一样，而且什么都不报。所以运行目录是个项目时，给 `args`
  补一个 `{{其它}}`，框里写 `-a`；或者先在那个目录里跑一次 `pi config` 把信任决定存下来。

## 依赖自负

`run.mjs` 只用 Node 自带的东西，不需要 `npm install`。要装依赖、要换脚本，都归这个目录自己 ——
MiCan 不装、不管、不解析。

## 这是样本，不是升级通道

改这个目录只影响这一份工作文件夹。想让五个画布都跟着变，自己把目录同步过去 ——
「不提供全局层」是这个软件认下的代价，`builtin/` 里那份只是让你少写一遍，不是替你管版本。
