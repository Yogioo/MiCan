entry: run.mjs
args: --prompt [[提示词]] --留会话 {{留会话}} {{模型}} {{工具}} {{技能}} {{MCP}} {{系统提示词}} {{其它}}
defaults:
  留会话: false
  模型: 空
  工具: 空
  技能: 空
  MCP: 空
  系统提示词: 空
  其它: 空
---

一份现成的 pi 封装。这是**一遍拷贝**，不是引用：把 `pi/` 整个目录拷进工作文件夹的
`extensions/` 底下，菜单里就多出「pi」这一项，拖出来即可用。

## 怎么接

`[[提示词]]` 优先当**路径**看：接一个文本节点上去，收到的是它那份 md 的绝对路径，`run.mjs`
读出正文从 stdin 递给 pi —— 顺便，提示词就成了画布上一个能看能改的方框。**路径读不到就当正文本身**：
一句短提示词直接在端口旁边的框里写（`hi`、`跑一下测试`）也能跑。看着像路径（带斜杠、或 .md 结尾）
却读不到，那是真错，会停在「提示词读不到」。

    文本节点（提示词）--[[提示词]]--> pi 节点 --> 文本节点（回话）

pi 在**节点的运行目录**里跑（节点自己设的 > 画布的运行目录 > 工作文件夹），
所以「看看这个仓库的 git 状态」「按这份提示词改代码」这类事，直接以那个目录为家。

## 留会话：`true` / `false`

八个输入里只有它不是一个「参数串」，它只认 `true` / `false`（拖出来是 `false`）：

- **`false`（默认）**：这次会话不落盘。链会重跑，定时器更是每 30 秒一趟 —— 留就是一路涨。
- **`true`**：这次会话落进 pi 自己的会话目录，过后能 `pi -r` 翻回来看它到底想了什么、调了哪个工具。
  要复盘的时候才打开它。

填了别的会停在这一步报错（`留会话 只认 true / false`）。

## 六个开关

每个开关的框里就是**要加给 pi 的那串参数**，原样拼进去，写什么是什么。
`空` 是唯一的保留词：这一个开关一个参数都不加，交给 pi 自己的配置。**框留空就是它** ——
留空时节点跑起来会拿清单里的默认值顶上，框里那句灰色的「默认 空」说的就是这事。
要显式地写出来也行，写在框里一样管用。

| 端口 | 框里写什么 | 写 `空` 的意思 |
| --- | --- | --- |
| 模型 | `--model sonnet`、`--model openai/gpt-4o` | pi 自己选的模型 |
| 工具 | `--tools read,bash,edit,write`、`--no-tools`、`--no-builtin-tools`、`--exclude-tools ask_question` | pi 的默认（全开） |
| 技能 | `--skill <技能目录>`、`--no-skills` | 按 pi 自己的配置扫 |
| MCP | `--mcp-config <配置文件>` | 用 pi 自己的 |
| 系统提示词 | `--append-system-prompt <md 路径>` | 不追加 |
| 其它 | 上面没有的，原样写：`--thinking high`、`-a`、`--no-extensions` | 什么都不加 |

几条要紧的：

- **路径带空格就在框里自己加引号**（`--skill "C:\我的 技能"`）。框里的话是先交给命令行再传给 pi 的，
  引号该加还是得加。
- `--append-system-prompt` 收文本，**也收文件路径**，所以直接给一份 md 的路径最省事。
- `--mcp-config` **不是 pi 本体认识的旗标**，是 pi 的 MCP 拓展注册的。没装那个拓展时它会被挂进
  pi 的 unknownFlags，不报错、也不生效 —— 所以它灵不灵取决于你到底装没装那个拓展。
- 多了不改代码：想再加一个开关（比如 pi 以后加了新旗标），往 `args` 那行补一个 `{{名字}}`，
  在 `defaults` 里给它写 `空` 就行。`run.mjs` 只认 `--prompt`、`--留会话` 和 `空`，别的一律转手。

## 拿到什么

stdout 永远是**一段合法 JSON**：

    {"ok":true,"text":"pi 的回话"}
    {"ok":false,"reason":"一句话说明哪里不对"}

`text` 里可以有换行（JSON 会转义），所以整份回话能顺着数据边灌进下游的文本节点。
要在链上分路，用提取节点取 `json:ok`，两根执行边上分别写 `true` / `false`。

**退出码跟着 pi 走：**

- pi 非 0（认证没了、超时、崩了）→ 节点标红、链停在这儿。那是**环境失败**，脚本不去粉饰它。
- pi 正常退出，但一个字没回 → 吐 `{"ok":false}` 且退出码 0。这是**业务空转**，交给链自己
  决定「重试 / 退给人」。

## 留会话那一处没有写在 args 里

`--no-session` 不在 `args` 那行 —— 改由 `留会话` 这个输入决定，`run.mjs` 里换。

- 想加 `-a`：运行目录若是个带本地配置（AGENTS.md、技能）的项目，在「其它」框里写上它，让 pi 这一次
  运行信任那些文件。

## 依赖自负

`run.mjs` 只用 Node 自带的东西，不需要 `npm install`。要装依赖、要换脚本，都归这个目录自己 ——
MiCan 不装、不管、不解析。

## 这是样本，不是升级通道

改这个目录只影响这一份工作文件夹。想让五个画布都跟着变，自己把目录同步过去 ——
「不提供全局层」是这个软件认下的代价，`builtin/` 里那份只是让你少写一遍，不是替你管版本。
